    03 / WHAT THIS MEANS

    Format is not trust.

    The specification defines how skills are packaged, not whether the author is genuine or the instructions are safe. This lightweight checker handles simple YAML scalars and flags complex YAML for manual review. For authoritative format validation, use the upstream skills-ref reference validator. For security, inspect all scripts, external resources, and runtime permissions separately.
